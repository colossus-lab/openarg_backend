Rules:

- Always use double-quoted identifiers for column names that contain spaces, accents, or special characters.
- CRITICAL: Most columns are stored as TEXT (even years, numbers, dates). ALWAYS compare with text literals: WHERE anio = '1980', NOT WHERE anio = 1980. Use CAST(col AS NUMERIC) only for aggregations or arithmetic, never for simple equality/filtering.
- NUMERIC CASTS — NEVER DISCARD ROWS TO MAKE A CAST WORK (CRITICAL). Argentine data mixes decimal formats in the SAME column: plain integers (`32291165`), comma decimals (`9403175,5`) and thousands separators (`1.234.567,89`). A filter like `col ~ '^\-?\d+\.?\d*$'` does NOT protect the query — it silently DROPS every comma-decimal row from the SUM and reports a total that is missing part of the universe. That is a wrong answer presented as a fact, which is worse than no answer. **NORMALIZE, DON'T FILTER.** For a TEXT column, cast through this expression:
  `CAST(NULLIF(replace(replace(col, '.', ''), ',', '.'), '') AS NUMERIC)`
  (strip thousands dots first, then turn the decimal comma into a dot). Guard only against NULL/empty, never against "shape":
  `WHERE col IS NOT NULL AND col <> ''`
  If a column genuinely mixes both `1.234,56` (AR) and `1234.56` (US) styles, prefer `to_number(col, '999G999G999D99')` or ask for the count instead of the sum — but never solve it by filtering rows out.
  **This applies ONLY when the column is typed as TEXT in the schema.** If the column is already `numeric`/`integer`/`bigint`/`double precision` (check the "Columnas (tipo):" lines in tables_context), do NOT wrap it — `replace()` and `~` both error on numeric types. Just use the column directly with `WHERE col IS NOT NULL`. Marts often expose pre-cast numeric columns (e.g. `cantidad_pasos`, `cantidad_hechos`, `monto`, `credito_vigente`).

NEVER answer a count question with `SELECT * ... LIMIT n`: a row dump capped at n rows is NOT a count, and the system will report those n rows as if they were the real total. - IMPORTANT: Use ST_DWithin() for proximity filters, NOT ST_Distance() < N.
