El modo datos no descuenta preguntas. Además, el modo respuestas tiene un cupo público total por día para todos los usuarios juntos. Si se agota, las consultas vuelven a funcionar a las 21:00. Lo vamos a ampliar a medida que crezca el uso, y los aportes de quienes lo usan son lo que nos permite hacerlo: cada respuesta con IA nos cuesta unos US$ 0,03.

¿Necesitás más consultas para un proyecto periodístico, académico o de gobierno? Escribinos a devops@colossuslab.org.

Qué se guarda

  • El texto de cada pregunta, asociado a tu clave, con la fecha, cuánto tardó y si respondió bien. Lo usamos para medir el uso, detectar abusos y mejorar las respuestas.
  • En el modo datos, qué herramienta usaste, cuándo, cuánto tardó y si anduvo, asociado a tu clave. No se guarda qué buscaste ni qué tablas leíste.
  • El programa desde el que llamás (por ejemplo Claude Code o Cursor, según lo informa tu cliente) y si fue por el MCP o por la API directa, para saber dónde se usa OpenArg.
  • Las preguntas frecuentes y sus respuestas se guardan en un caché, para responder más rápido cuando alguien pregunta lo mismo.
  • Tu cuenta: el email y el nombre de Google con los que creaste la clave.
Qué no se guarda: las conversaciones con tu asistente. OpenArg sólo ve la pregunta que el asistente le manda, no el resto del chat.

No pongas datos personales ni información confidencial en las preguntas. La política completa está en openarg.org/privacy.

Cómo usar las respuestas

  • OpenArg usa un modelo de lenguaje para leer las tablas y redactar. Puede equivocarse.
  • Las fuentes te llevan al dataset original: usalas para verificar antes de publicar un número.
  • Las advertencias no son decorativas. Si una respuesta dice que el total está incompleto, lo está.
  • OpenArg refleja lo que publica cada organismo, con sus demoras y sus cambios de metodología.

Uso aceptable

No uses la clave para automatizar consultas masivas, eludir los límites con varias cuentas ni para nada que no sean preguntas sobre datos públicos. Podemos revocar las claves que se usen así.
