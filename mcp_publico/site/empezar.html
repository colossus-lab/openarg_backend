Empezar

Conectalo en dos minutos.

Necesitás una clave gratis de OpenArg y un cliente que hable MCP.

  1. Conseguí tu clave

    Entrá a openarg.org/desarrolladores con tu cuenta de Google y tocá Crear clave. Empieza con oarg_sk_ y se muestra una sola vez: copiala a un lugar seguro.

    Si la perdés, generá otra: la anterior queda revocada.

  2. Agregá OpenArg a tu cliente

    La dirección del servidor es https://mcp.openarg.org/mcp y la clave va en el header Authorization. Reemplazá oarg_sk_TU_CLAVE por la tuya.

    En la terminal:

    claude mcp add --transport http openarg https://mcp.openarg.org/mcp \
  --header "Authorization: Bearer oarg_sk_TU_CLAVE"

    Con --scope user queda disponible en todos tus proyectos.

    Claude Desktop se conecta a servidores remotos con clave a través de mcp-remote (necesita Node.js). Abrí Configuración → Desarrollador → Editar configuración y agregá:

    claude_desktop_config.json
    {
  "mcpServers": {
    "openarg": {
      "command": "npx",
      "args": [
        "-y", "mcp-remote", "https://mcp.openarg.org/mcp",
        "--header", "Authorization:${OPENARG_AUTH}"
      ],
      "env": { "OPENARG_AUTH": "Bearer oarg_sk_TU_CLAVE" }
    }
  }
}

    Reiniciá Claude Desktop después de guardar.

    En ~/.cursor/mcp.json (o .cursor/mcp.json dentro de un proyecto):

    mcp.json
    {
  "mcpServers": {
    "openarg": {
      "url": "https://mcp.openarg.org/mcp",
      "headers": { "Authorization": "Bearer oarg_sk_TU_CLAVE" }
    }
  }
}

    En .vscode/mcp.json. VS Code te pide la clave la primera vez y la guarda cifrada:

    .vscode/mcp.json
    {
  "inputs": [
    { "type": "promptString", "id": "openarg-key",
      "description": "Clave de OpenArg (oarg_sk_…)", "password": true }
  ],
  "servers": {
    "openarg": {
      "type": "http",
      "url": "https://mcp.openarg.org/mcp",
      "headers": { "Authorization": "Bearer ${input:openarg-key}" }
    }
  }
}

  3. Preguntá

    Pedile algo a tu asistente que necesite datos, por ejemplo:

    • ¿Cuál fue la tasa de desempleo del último trimestre publicado?
    • Mostrame la evolución mensual del IPC en 2025.
    • ¿Cómo se reparten las bancas de Diputados por bloque?

    Cuanto más concreta la pregunta (indicador, período, lugar), mejor la respuesta.

Cuidá tu clave. No la subas a un repositorio público ni la pegues en un chat. Si se filtró, generá una nueva en openarg.org/desarrolladores y la anterior deja de funcionar.
